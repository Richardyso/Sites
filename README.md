# Sites

Coleção de sites e aplicações web desenvolvidos com HTML, CSS, JavaScript e Node.js. O repositório contém projetos front-end e full stack, com diferentes abordagens e níveis de complexidade. Os deploys são feitos via Netlify ou Vercel, explorando boas práticas de desenvolvimento web.

## 📁 Projetos

### 🌐 Giro Digital
**Descrição:** Site institucional para agência de marketing digital oferecendo serviços de branding, redes sociais e websites para pequenos negócios em Portugal.

**Tecnologias:** HTML5, CSS3, JavaScript (Vanilla)

**Funcionalidades:**
- ✅ Sistema de seleção de idiomas (PT-PT, PT-BR, ES-ES, EN-US) com tradução automática
- ✅ Conversor de moedas automático (EUR, BRL, USD)
- ✅ Design responsivo para mobile, tablet e desktop
- ✅ Seletor de idiomas com bandeiras lado a lado
- ✅ Atualização automática do ano no copyright
- ✅ Seções: Hero, Preços, Serviços, Sobre, FAQ, Termos

**Links:**
- Site: [girodigital.netlify.app](https://girodigital.netlify.app/)

## ✨ Funcionalidades Comuns

### Sistema de Tradução
Todos os sites principais possuem sistema de tradução multi-idioma com suporte para:
- Português (Portugal)
- Português (Brasil)
- Inglês (EUA)
- Espanhol (Espanha)

### Atualização Automática de Ano
Implementado em todos os sites para manter o copyright sempre atualizado sem necessidade de manutenção manual.

### Design Responsivo
Todos os projetos são totalmente responsivos, adaptando-se perfeitamente a:
- 📱 Mobile (< 768px)
- 📱 Tablet (768px - 1024px)
- 💻 Desktop (> 1024px)
