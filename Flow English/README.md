# Flow English - Site Oficial

Site educacional para o curso Flow English de conversação em inglês.

## 🚀 Melhorias Implementadas

### ✅ Funcionalidades
- **Teste de Nivelamento Simplificado**: Removidas as respostas do código cliente
- **Progresso Salvo**: O progresso do teste é salvo automaticamente no navegador
- **Barra de Progresso**: Visual do progresso do teste em tempo real
- **Responsividade Total**: Funciona perfeitamente em todas as telas
- **Menu Mobile**: Menu hambúrguer para dispositivos móveis
- **Animações Suaves**: Transições e animações CSS modernas

### 🔒 Segurança e Performance
- Meta tags de SEO otimizadas
- Headers de segurança configurados
- PWA ready com manifest.json
- Lazy loading preparado
- Cache headers otimizados

### ♿ Acessibilidade
- Labels ARIA em todos os elementos interativos
- Skip link para navegação rápida
- Contraste adequado de cores
- Formulários acessíveis

### 📱 Responsividade
- Desktop (1024px+)
- Tablet (768px - 1024px)
- Mobile (480px - 768px)
- Mobile pequeno (320px - 480px)

## 📁 Estrutura de Arquivos

```
Ricardo/
├── index.html          # Página principal
├── manifest.json       # PWA manifest
├── _headers           # Headers de segurança Netlify
├── assets/
│   ├── styles.css     # Estilos CSS
│   ├── script.js      # JavaScript
│   └── imagens/
│       └── og.png     # Imagem Open Graph
```
