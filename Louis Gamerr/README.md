# 🎮 Louis Gamer - Website

Site oficial do Louis Gamer com tema anime noir em preto e branco.

## 🚀 Deploy no Netlify

### Opção 1: Deploy Manual
1. Faça o download de todos os arquivos do projeto
2. Acesse [app.netlify.com](https://app.netlify.com)
3. Arraste a pasta do projeto para a área de deploy
4. Pronto! Seu site estará online

### Opção 2: Deploy via Git
1. Suba o projeto para um repositório GitHub
2. Conecte o repositório ao Netlify
3. Configure o deploy automático

## 🔧 Personalização

### Alterar Links
Edite o arquivo `index.html` e procure pelas seções de links para atualizar URLs.

### Alterar Cores
No arquivo `assets/styles/style.css`, modifique as variáveis CSS no `:root`.

### Adicionar Novas Seções
1. Adicione o HTML em `index.html`
2. Estilize em `style.css`
3. Adicione animações em `script.js`
